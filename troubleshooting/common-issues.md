# Частые проблемы

## Мод не появляется в списке модов

**Причины:**
- Неверная версия Minecraft (требуется 1.21.11)
- Fabric API не установлен в папке `mods`
- JAR-файл повреждён или не совместим

**Решение:**
1. Проверьте версию Minecraft в профиле Fabric
2. Убедитесь, что Fabric API лежит в `mods`
3. Скачайте JAR-файл заново

## Меню не открывается (Right Shift)

**Причины:**
- Клавиша перехвачена другим модом
- Мод не загружен правильно
- Лицензия неактивна (для niektóх функций)

**Решение:**
1. Проверьте консоль на ошибки при запуске
2. Попробуйте переназначить клавишу
3. Убедитесь, что мод активен в списке модов

## Модули не работают

**Причины:**
- Нет активной лицензии
- Лицензия истекла
- Модуль выключен в настройках

**Решение:**
1. Активируйте лицензионный ключ
2. Проверьте, что модуль включён в меню
3. Проверьте `License.ok()` в логах

## Ошибка «Unable to delete latest.log»

**Причина:** Клиент всё ещё открыт, файл лога заблокирован.

**Решение:** Закройте клиент и попробуйте снова. Если клиент завис — выполните `gradlew --stop`.

## HUD элементы не отображаются

**Причины:**
- Модуль HUD выключен
- Элементы скрыты в редакторе HUD
- Конфликт с другим модом

**Решение:**
1. Включите модуль HUD в настройках
2. Откройте редактор HUD и проверьте видимость элементов
3. Сбросьте настройки HUD к умолчанию (кнопка ↺)

## Конфиг не сохраняется

**Причины:**
- Недостаточно места на диске
- Файл конфига открыт в другой программе
- Права доступа к папке

**Решение:**
1. Освободите место на диске
2. Закройте все программы, работающие с конфигом
3. Проверьте права на папку `config/`
