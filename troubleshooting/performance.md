# Производительность

## Низкий FPS

**Решения:**
1. Включите модуль **Optimization** (ZakoOpt, occlusion, reuse)
2. Уменьшите настройки рендера в Minecraft
3. Отключите ненужные модули визуальных эффектов
4. Уменьшите плотность стекла в модуле Interface

## Лаги при открытии меню

**Решения:**
1. Отключите анимации в модуле Interface
2. Уменьшите количество элементов HUD
3. Отключите предпросмотр в настройках Interface

## Высокое использование памяти

**Решения:**
1. Выделите больше оперативной памяти Minecraft (от 4 ГБ)
2. Отключите запись экрана, если не нужна
3. Удалите старые записи из Records View

## Лаги в игре с модом

**Решения:**
1. Включите **Occlusion** в Optimization (скрытие объектов за стенами)
2. Отключите Target Render, если не нужен ESP
3. Отключите Ban Effects, если не нужны визуальные эффекты банов

## Проверка оптимизации

Используйте команду `audit()` для проверки работы оптимизации (1 + аудит).

## Поддержка

Если проблемы не решаются, обратитесь в поддержку с указанием:
- Версии мода и Minecraft
- Списка установленных модов
- Лога `latest.log`
- Описания проблемы
