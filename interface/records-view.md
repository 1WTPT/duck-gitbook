# Записи экрана (Records View)

Интерфейс для просмотра и управления записями экрана.

## Возможности

- Просмотр списка записей
- Воспроизведение записей
- Удаление старых записей
- Управление клипами до бана (+5 секунд)

## Интеграция с OBS

Запись может интегрироваться с OBS через модуль `Obs` для профессиональной записи и трансляции.

## Хранение

Записи хранятся в папке записей мода и управляются через `RecordsView` и `Records` класс.
