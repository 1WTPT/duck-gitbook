# Страницы меню

Каждый модуль Duck Util имеет свою страницу в меню с настройками.

## Типы настроек на страницах

| Тип | Описание |
|-----|----------|
| **Bool** | Флажок вкл/выкл |
| **Slider** | Ползунок с числовым значением |
| **Mode** | Список вариантов (выпадающий) |
| **Multi** | Несколько флажков |
| **Text** | Текстовое поле |
| **Color** | Выбор цвета из палитры |
| **Bind** | Привязка клавиши |

## Элементы страницы

- **Подпись** — название настройки
- **Описание** — подсказка при наведении (если включено в Interface)
- **Тег** — плашка «Тест», «Важно», «Дебаг» (если установлена)
- **Раздел** — заголовок над группой настроек
- **Кнопка сброса** (↺) — сбрасывает настройки к умолчанию (если есть изменения)

## Скрытые настройки

Некоторые настройки скрыты (`visibleWhen`) и показываются только при выполнении условия (например, настройка «Сила» только в режиме «Гамма»). Скрытые строки плавно сворачиваются.

## Локальные настройки

Настройки с пометкой «Только этот компьютер» не попадают в общий конфиг (.duck) и не синхронизируются между ПК. Это ключи, пути, ники на скриншотах и т.п.
