# Экран лицензии

Экран лицензии отображается при отсутствии активной лицензии Duck Util.

## Состояния

| Состояние | Описание |
|-----------|----------|
| **Нет ключа** | Поле для ввода лицензионного ключа |
| **Активация** | Процесс проверки ключа на сервере |
| **Активна** | Лицензия активна, полный доступ к функциям |
| **DEV** | В режиме разработчика лицензия не требуется |

## Без лицензии

Без лицензии доступны только:
- Окно ключа лицензии
- Тема оформления (Theme)
- Твики оптимизации (Optimization)

Все остальные модули отключены (проверка `License.ok()` в `Module.isEnabled()`).

## Получение ключа

1. Нажмите кнопку получения ключа в окне лицензии.
2. Следуйте инструкциям на сервере лицензирования (`duck-license-server/`).
3. Вставьте полученный ключ в поле.
4. Нажмите «Активировать».

## Проверка лицензии

Лицензия проверяется при каждом запуске клиента. Ключ привязан к HWID компьютера и выдаёт токен Ed25519 (`uid`).
