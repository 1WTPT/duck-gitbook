# Статистика (Stats View)

Экран статистики игры и работы с модом.

## Показываемая информация

| Метрика | Описание |
|---------|----------|
| **Время игры** | Таймер работы (Playtime / WorkTimer) |
| **КПД** | Коэффициент полезного действия (KpdGoals) |
| **Баны** | Количество отслеженных банов |
| **Цели** | Статистика по отслеженным целям |

## Отчёты

- Дневной отчёт и КПД по МСК (`BanLog.MSK`)
- Цель в WorkHud — `KpdGoals.hudGoal`
- Отчёты сохраняются в `Duck Util/Резервный лог банов.txt`

## HUD статистики

Элемент `WorkHud` на экране показывает текущий таймер работы и цель КПД.
