# Меню цели

Меню цели предоставляет быстрые действия над выбранным игроком.

## Открытие

Клавиша **V** (в игре, с лицензией). Если рядом нет игроков и цель не выбрана — показывается уведомление.

## Виды меню

| Вид | Описание |
|-----|----------|
| **Окно** | Обычное окно со списком действий |
| **Колёсико** | Круговое меню для быстрого доступа |
| **Компакт** | Компактная строка с основными действиями |

## Действия

| Действие | Описание |
|----------|----------|
| **Окно игрока** | Открыть профиль игрока |
| **Колесо** | Круговое меню действий |
| **Компакт** | Быстрый доступ к основным действиям |
| **Сброс** (off) | Серая строка — сброс цели |

## Текущая цель

Текущая цель хранится в `TargetManager.menuTarget()`. Если цель меняется, меню обновляется автоматически.

## Технология

Меню использует `TargetActions` для действий над игроками и `TargetCompactScreen` / `TargetMenuScreen` / `TargetWheelScreen` для разных видов отображения.
