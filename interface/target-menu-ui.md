# Меню цели

Находясь в игровом мире, нажмите **V**, чтобы открыть меню цели. Если рядом есть несколько игроков, выберите нужного по имени.

В меню доступны действия, которые поддерживаются вашей версией Duck Util и сервером. Перед отправкой команды ещё раз проверьте выбранного игрока.
