# Редактор HUD

Редактор HUD позволяет настраивать расположение и оформление элементов на экране.

## Открытие

Редактор открывается из главного меню Duck Util через раздел HUD.

## Основные действия

| Действие | Описание |
|----------|----------|
| **Перетаскивание** | Зажмите ЛКМ на элементе и перетащите |
| **Изменение размера** | С 흐름 угла или края элемента |
| **Скрытие/показ** | Переключатель видимости у элемента |
| **Оформление** | Выбор стиля элемента из списка |

## Стили оформления

Каждый элемент HUD может иметь свой стиль оформления:
- Встроенные стили
- Свои стили из Редактора (`HudKind`)
- Стили меняются на лету через выпадающий список

## Сохранение

Макет HUD сохраняется автоматически при перемещении элементов. Настройки привязаны к компьютеру (локальный конфиг).

## Клики в чате

Клики по элементам HUD в чате обрабатываются в `DuckUtilClient`. Правка в меню — через `DuckScreen.peekOf`.
