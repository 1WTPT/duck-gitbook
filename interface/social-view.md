# Социальный экран (Social View)

Экран социальных функций Duck Util.

## Вкладки

| Вкладка | Описание |
|---------|----------|
| **В сети** | Список игроков онлайн |
| **Топы** | Рейтинги по играм (дурак, бильярд и т.д.) |
| **Игры** | Активные игры и приглашения |

## Сообщество

- Статус друзей (онлайн/офлайн)
- Топы игроков (дурак считает сервер)
- Бильярд — `social.js` и `/play/*` команды
- Дурак — `durak.js` и `/durak/*` команды
- Змейка — `SnakeScreen` с рекордом (apples) в локальном конфиге «snake»

## КПД

Коэффициент полезного действия синхронизируется через `KpdSync` → `kpd.js`.
