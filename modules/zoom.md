# Zoom — зум

Модуль **Zoom** позволяет приближать изображение, как бинокль.

## Настройки

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| **Включён** | Выкл | Включить зум |
| **Клавиша** | Не назначена | Клавиша для активации зума |
| **Уровень зума** | 2.0x | Во сколько раз приближать изображение |

## Использование

1. Назначьте клавишу для зума в настройках модуля.
2. В игре зажмите клавишу — изображение приблизится.
3. Отпустите клавишу — зум выключится.

Клавиша по умолчанию не назначена (GLFW_KEY_UNKNOWN).
