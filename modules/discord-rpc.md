# Discord RPC — статус в Discord

Модуль **Discord RPC** отображает статус игры в Discord Rich Presence.

## Настройки

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| **Включён** | Выкл | Показывать статус в Discord |
| **Канал** | Release | Канал сборки (в названии версии) |

## Отображаемая информация

- Версия мода: `Duck <версия> <канал>`
- Текущее действие (в меню / в игре)
- Метка `{ver}` в Discord RPC

Версия берется из `gradle.properties` и записывается в `min-version.json` сервера лицензирования.
