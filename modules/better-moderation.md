# Better Moderation — улучшенная модерация

Модуль **Better Moderation** расширяет панель модерации дополнительными функциями.

## Возможности

| Функция | Описание |
|---------|----------|
| **Вкладка модерации** | Дополнительная вкладка в интерфейсе модерации |
| **Защита ника** | Name/RankProtect — защита от подмены ника и ранга |
| **Анти спект-линк** | Защита от SpecLink — слежения через спектратор |
| **Скан при /dupeip** | Автоматический скан при использовании команды дупеипа |

## Команды

- `/dp` — действие модерации
- `/wc` — поиск игроков
- `/rmc` — команда модерации

Все команды обрабатываются в `DuckUtilClient`.
