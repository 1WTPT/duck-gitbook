# Custom Fog — туман

Модуль **Custom Fog** настраивает параметры тумана в мире.

## Настройки

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| **Включён** | Выкл | Включить настройку тумана |
| **Цвет тумана** | Авто | Цвет тумана |
| **Плотность** | 0.0 | Плотность тумана (0.0 — 1.0) |
| **Начало** | 0.0 | Дистанция начала тумана |
| **Конец** | 0.0 | Дистанция конца тумана |

## Описание

Позволяет полностью настроить внешний вид тумана в игре — от полного отсутствия до густого цветного тумана.
