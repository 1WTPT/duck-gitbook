# Target HUD — HUD цели

Модуль **Target HUD** выводит панель информации о выбранной цели на экран.

## Информация на панели

| Поле | Описание |
|------|----------|
| **Ник** | Имя игрока-цели |
| **Дистанция** | Расстояние до цели в блоках |
| **Здоровье** | Текущее здоровье цели (сердечки) |
| **Эффекты** | Активные зельевые эффекты |
| **Одежда** | Надетые предметы брони |
| **Предмет в руке** | Что hält цель в руках |

## Настройки

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| **Включён** | Выкл | Включить HUD цели |
| **Позиция** | — | Место размещения панели на экране |
| **Размер** | 1.0x | Масштаб панели |
| **Прозрачность** | 90% | Плотность фона панели |
| **Показывать здоровье** | Вкл | Отображать сердечки здоровья |
| **Показывать эффекты** | Вкл | Отображать зельевые эффекты |

## Сброс цели

Цель сбрасывается при выходе игрока с сервера, смене мира или вручную через меню цели.
