# Cheat Detector — детектор читов

Модуль **Cheat Detector** обнаруживает использование читов другими игроками.

## Возможности

| Функция | Описание |
|---------|----------|
| **Детект аимбота** | Обнаружение автоматического прицеливания |
| **Детект лета** | Обнаружение полёта без креативного режима |
| **Детект скорости** | Обнаружение ускоренного движения |
| **Детект reach** | Обнаружение удара на расстоянии |
| **Команды** | `/cdstart ник|me|all [cheat|legit]` — начать проверку |

## Настройки

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| **Включён** | Выкл | Включить детект читов |
| **Чувствительность** | — | Порог срабатывания детекции |
| **Уведомления** | Вкл | Показывать уведомления о подозрительных действиях |

## Результаты

Результаты проверки записываются в лог читов и могут быть использованы для ревизии игроков через `/revise finish <чит>`.
