# Target Render — отрисовка цели

Модуль **Target Render** отвечает отображение выбранной цели в 3D мире (ESP).

## Возможности

| Функция | Описание |
|---------|----------|
| **Контур цели** | Обводка вокруг игрока-цели |
| **Линия прицела** | Линия от игрока к цели |
| **Дистанция** | Отображение расстояния до цели |
| **Имя цели** | Отображение ника цели над головой |
| **Эффекты** | Отображение активных эффектов цели |

## Настройки

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| **Включён** | Выкл | Включить отрисовку цели |
| **Цвет контура** | Авто | Цвет обводки вокруг цели |
| **Цвет линии** | Авто | Цвет линии от игрока к цели |
| **Показывать дистанцию** | Вкл | Показывать расстояние до цели |
| **Показывать имя** | Вкл | Показывать ник цели |
| **Макс. дистанция** | — | Максимальная дистанция отрисовки |
