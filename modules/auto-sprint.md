# Auto Sprint — автоспринт

Модуль **Auto Sprint** автоматически включает спринт при движении.

## Настройки

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| **Включён** | Выкл | Включить автоспринт |
| **Только вперёд** | Вкл | Спринт только при движении вперёд |

## Описание

При движении персонажа вперёд спринт включается автоматически без необходимости нажимать клавишу спринта.
