# Target Arrow — стрелка цели

Модуль **Target Arrow** отображает стрелку на экране, указывающую направление к текущей цели.

## Настройки

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| **Включён** | Выкл | Включить стрелку цели |
| **Цвет** | Авто | Цвет стрелки |
| **Размер** | 1.0 | Размер стрелки на экране |
| **Позиция** | — | Место размещения стрелки |

## Описание

Когда цель находится за пределами экрана, стрелка показывает направление к ней, помогая быстро найти игрока.
