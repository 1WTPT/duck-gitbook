# Cheat Base — база читов

Модуль **Cheat Base Module** — база известных читов и команд для ревизии. Всегда включён.

## Возможности

| Функция | Описание |
|---------|----------|
| **База читов** | Список известных чит-клиентов и их особенности |
| **Команды ревизии** | `/cheats/*` — команды для проверки игроков |
| **Трекинг** | Отслеживание подозрительных действий |

## Команды

Команды доступны через `/cheats/*` и `/revise finish <чит>` для завершения проверки игрока.

Модуль не имеет переключателя и всегда активен с настройками по умолчанию.
