# Player Model — модель игрока

Модуль **Player Model** изменяет модель игрока.

## Настройки

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| **Включён** | Выкл | Включить изменение модели |
| **Модель** | Стандартная | Выбор модели игрока |

## Доступные модели

В модели могут использоваться кастомные модели из ресурсов мода, включая модели из файла `models/rudy.glb`.
