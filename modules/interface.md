# Interface — настройки меню

Модуль **Interface** содержит настройки главного меню Duck Util. Модуль всегда активен (без переключателя).

## Настройки

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| **Плотность фона** | 0.8 | Насколько тёмное и плотное стекло под меню (0.2 — 1.0) |
| **Плотность HUD** | 90% | Плотность стекла под элементами HUD, уведомлениями и мини-настройками |
| **Свечение краёв** | Выкл | Мягкая тень под стеклом меню и HUD |
| **Размер** | 1.0x | Масштаб меню и окон Duck Util (0.7 — 1.3x) |
| **Фото на фоне** | — | Своя картинка под стеклом меню (PNG, JPG, BMP, GIF) |
| **Размещение фото** | Заполнить | Заполнить (обрезка по краям) или Растянуть (весь фото) |
| **Затемнение фото** | 70% | Тёмное стекло поверх фото для лучшей читаемости текста |
| **Прозрачность фото** | 0% | Сквозь фото видно игру за меню |
| **Размытие фото** | 4 px | Мягкое размытие фото |
| **Анимации** | Вкл | Плавные появления, переходы и подсветки |
| **Скорость анимаций** | 1.0x | Во сколько раз быстрее анимации меню (0.5 — 2.0x) |
| **Звуки** | Вкл | Тихие щелчки при нажатиях в меню |
| **Громкость** | 0.5 | Громкость звуков меню (0.1 — 1.0) |
| **Щелчки слайдеров** | Вкл | Щелчок на каждом шаге при перетаскивании слайдера |
| **Подсказки над меню** | Вкл | Описание модуля или настройки под курсором |
| **Предпросмотр** | Вкл | Окно справа с моделью Ban Effect или Target ESP |

## Подсказки

При включённой опции «Подсказки над меню» при наведении на модуль или настройку показывается описание — то, что указано в документации разработчика.
