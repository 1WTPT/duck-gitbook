# Target Menu — меню цели

Модуль **Target Menu** добавляет контекстное меню для выбранного игрока.

## Открытие

Меню цели открывается клавишей **V** (в игре, с лицензией).

## Действия в меню

| Действие | Описание |
|----------|----------|
| **Профиль** | Посмотреть профиль игрока |
| **Копировать ник** | Скопировать ник в буфер обмена |
| **Личное сообщение** | Отправить ЛС игроку |
| **Отслеживание** | Добавить игрока в отслеживание |
| **Модерация** | Действия модерации (бан, кик, мут) |
| **Компакт** | Компактный вид меню |
| **Колёсико** | Круговое меню действий |

## Виды меню

- **Окно** — обычное окно со списком действий
- **Колёсико** — круговое меню для быстрого доступа
- **Компакт** — компактная строка с основными действиями

Если рядом нет игроков и цель не выбрана, показывается уведомление.
