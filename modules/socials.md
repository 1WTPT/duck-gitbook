# Socials — социальные настройки

Модуль **Socials** управляет социальными функциями мода.

## Настройки

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| **Включён** | Выкл | Включить социальные функции |
| **Статус «В сети»** | Вкл | Показывать статус онлайн друзей |
| **Топы игроков** | Вкл | Показывать топы по играм |
| **КПД** | Вкл | Синхронизировать коэффициент полезного действия |

## Социальные функции

- Список друзей и их статус
- Топы по дураку, бильярду и другим играм
- Синхронизация КПД через `kpd.js`
- Чат в играх
