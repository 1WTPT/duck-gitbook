# Branch — ветка аккаунтов

Модуль **Branch** строит дерево связанных аккаунтов через команды сервера.

## Возможности

- Построение дерева аккаунтов через `/dupeip`, `/history`, `/report`
- Визуализация связей между игроками
- Настройка скорости выполнения команд (задержки)

## Настройки

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| **Включён** | Выкл | Включить ветвление аккаунтов |
| **Скорость** | — | Задержки между командами (настраивается шестерёнкой) |
| **Сброс** | ↺ | Сброс настроек к умолчанию |

## Использование

Откройте «Ветку» из меню мода, выберите игрока и начните сканирование связанных аккаунтов.
