# HUD — элементы на экране

Модуль **HUD** управляет элементами отображения на экране (heads-up display).

## Элементы HUD

| Элемент | Описание |
|---------|----------|
| **Watermark** | Версия мода, канал и информация о сессии |
| **Медиаплеер** | Текущий трек, исполнитель, обложка |
| **Цель** | Информация о выбранном игроке: дистанция, здоровье, эффекты |
| **Координаты** | Позиция игрока (X, Y, Z) и направление взгляда |
| **FPS** | Количество кадров в секунду |
| **Задержка (Ping)** | Задержка соединения с сервером |

## Настройки HUD

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| **Плотность HUD** | 90% | Плотность стекла под элементами HUD и уведомлениями |
| **Масштаб** | 1.0x | Размер элементов HUD |

## Редактор HUD

Через редактор HUD можно:
- Перетаскивать элементы мышкой по экрану
- Изменять оформление каждого элемента
- Скрывать или показывать элементы
- Настраивать цвета и прозрачность

Макет HUD сохраняется в локальном конфиге компьютера.

## Сохранение

Настройки HUD сохраняются в общем конфиге (.duck) и синхронизируются между компьютерами (кроме локальных параметров).
