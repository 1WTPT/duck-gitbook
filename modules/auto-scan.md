# Auto Scan — автоскан

Модуль **Auto Scan** автоматически сканирует игроков на сервере.

## Настройки

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| **Включён** | Выкл | Включить автоскан |
| **Клавиши** | F6 / F7 | Клавиши для запуска/остановки сканирования |
| **Задержки** | — | Задержки между командами сканирования |

## Команды

- `/wc` — найти игроков (используется в автоскане)
- F6 — начать сканирование
- F7 — остановить сканирование

Настройки задержек команд находятся в классе `AutoScanModule`.
