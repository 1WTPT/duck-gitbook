# Optimization — оптимизация

Модуль **Optimization** содержит твики для повышения производительности клиента.

## Компоненты

| Компонент | Описание |
|-----------|----------|
| **ZakoOpt 1.2.0** | Оптимизация рендеринга мира и объектов |
| **Reuse** | Переиспользование объектов кадра вместо создания новых |
| **Occlusion** | Не отрисовывать объекты за стенами |

## Настройки

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| **Включён** | Выкл | Включить оптимизацию |
| **defaultRequire** | 0 | Порог срабатывания; 0 — промах молчит |

## Проверка

Для проверки работы оптимизации используется команда `audit()` (1 + аудит). Визуальные модули Optimization работают даже когда основной модуль выключен (все флаги твиков — ложь).

## Лицензия

Твики оптимизации работают даже без лицензии мода.
