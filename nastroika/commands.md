# Команды

Часть команд Duck Util — это быстрые сокращения для команд сервера. Для них нужны активная лицензия и поддержка соответствующей команды самим сервером.

| Команда                | Что делает                                                                                               |
| ---------------------- | -------------------------------------------------------------------------------------------------------- |
| `/dp ник`              | Сокращение для серверной команды `/dupeip ник` — проверка связанных аккаунтов.                           |
| `/wc ник`              | Сокращение для серверной команды `/wanted check ник`.                                                    |
| `/rmc ник`             | Сокращение для серверной команды `/report menu ник cheat`.                                               |
| `/лог ник1 ник2`       | Запрашивает игровые логи указанных игроков через интеграцию VK. Доступность зависит от настроек проекта. |
| `/cdstart ник [метка]` | Начинает запись для игрока. Для метки укажите `cheat` или `legit`; также можно указать `me` или `all`.   |
| `/cdstop`              | Завершает текущую запись Cheat Detector.                                                                 |

Команды, которые выполняются на сервере, не добавляют серверу новых возможностей: если сервер не знает такую команду или у вас нет прав, он отклонит запрос. Для команд Cheat Detector активная лицензия также обязательна.

Основные действия доступны из меню мода, открываемого клавишей **Right Shift**. См. также [клавиши](keybindings.md).

## История по красному нику

Нажмите на красный ник в чате, в том числе в ответе `/dupeip`, чтобы отправить `/hist ник`. Для команды нужны серверные права; включать автоскан для такого клика не требуется.

Дополнительная подсказка «Показать историю / Нажмите на ник» убрана в **3.4**. Собственные подсказки сервера сохраняются.

## Автоматические /key и /ca teamtg

[Auto Key](../moduli/auto-key.md) в разделе **Разное** отправляет `/key` после входа. Чекбокс **Авто /ca teamtg** включает дополнительную команду с задержкой **0–10000 мс** после отправки ключа; по умолчанию чекбокс выключен. Эти команды должен поддерживать игровой сервер.
