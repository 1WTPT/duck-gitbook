# Команды

Часть команд Duck Util — это быстрые сокращения для команд сервера. Для них нужны активная лицензия и поддержка соответствующей команды самим сервером.

| Команда                | Что делает                                                                                               |
| ---------------------- | -------------------------------------------------------------------------------------------------------- |
| `/dp ник`              | Сокращение для серверной команды `/dupeip ник` — проверка связанных аккаунтов.                           |
| `/wc ник`              | Сокращение для серверной команды `/wanted check ник`.                                                    |
| `/rmc ник`             | Сокращение для серверной команды `/report menu ник cheat`.                                               |
| `/лог ник1 ник2`       | Запрашивает игровые логи указанных игроков через интеграцию VK. Доступность зависит от настроек проекта. |
| `/settimer минуты`     | Запускает таймер проверки на 1–60 минут, когда проверка уже началась.                                    |
| `/cdstart ник [метка]` | Начинает запись для игрока. Для метки укажите `cheat` или `legit`; также можно указать `me` или `all`.   |
| `/cdstop`              | Завершает текущую запись Cheat Detector.                                                                 |

Команды, которые выполняются на сервере, не добавляют серверу новых возможностей: если сервер не знает такую команду или у вас нет прав, он отклонит запрос. Для команд Cheat Detector и таймера активная лицензия также обязательна.

Основные действия доступны из меню мода, открываемого клавишей **Right Shift**. См. также [клавиши](keybindings.md).

## История по красному нику

В **3.3** наведите курсор на красный ник в чате, в том числе в ответе `/dupeip`: подсказка покажет `/hist ник`. Нажатие отправит команду серверу. Для неё нужны права на `/hist`; включать автоскан для такого клика не требуется.
