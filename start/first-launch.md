# Первый запуск

После установки мода и запуска клиента вы увидите изменённое главное меню Duck Util.

## Открытие меню мода

В любой момент (в главном меню или в игре) нажмите **Right Shift** — откроется главное окно Duck Util с قائمة модулей.

## Лицензия

При первом запуске без лицензии доступно только окно ввода ключа. Чтобы получить полный доступ:

1. Нажмите кнопку получения ключа в окне лицензии.
2. Следуйте инструкциям на сервере лицензирования.
3. Вставьте ключ в поле и нажмите «Активировать».

Без лицензии модули отключены, работают только:
- Тема оформления (Theme)
- Твики оптимизации (Optimization)
- Окно ключа лицензии

## Первичная настройка

В меню мода рекомендуется:

1. Посмотреть список [модулей](modules/) и включить нужные.
2. Настроить [интерфейс](modules/interface.md) (прозрачность, масштаб, анимации).
3. Выбрать [тему](modules/theme.md) оформления.
4. Настроить [HUD](modules/hud.md) элементы под себя.
5. Изучить [клавиши](reference/keybindings.md) и [команды](reference/commands.md).

## Где хранятся файлы

| Файл | Путь | Описание |
|------|------|----------|
| Общий конфиг | `Duck Util/` (облако / `.duck`) | Настройки, синхронизируемые между ПК |
| Локальный конфиг | `config/duck-util-local.json` | Только этот ПК (ключи, пути, ники) |
| Логи | `logs/latest.log` | Лог клиента и мода |
| Баны | `Duck Util/Баны/` | Архив банов |
| Резерв | `Duck Util/Резервный лог банов.txt` | Полный лог всех банов |

## Горячие клавиши по умолчанию

| Клавиша | Действие |
|---------|----------|
| `Right Shift` | Открыть главное меню Duck Util |
| `V` | Открыть меню цели (в игре, с лицензией) |

Клавиши можно перенастроить в настройках интерфейса или через файл привязок.
