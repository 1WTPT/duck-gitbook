# Установка

Duck Util distribuируется как JAR-файл для Fabric Loader.

## Требования

- Minecraft **1.21.11**
- [Fabric Loader](https://fabricmc.net/use/installer/)
- [Fabric API](https://www.curseforge.com/minecraft/mc-mods/fabric-api) (рекомендуемая версия: `0.141.6+1.21.11`)
- Java 25 (JDK 25) для запуска клиента

## Установка Fabric

1. Скачайте [Fabric Installer](https://fabricmc.net/use/installer/).
2. Запустите установщик и выберите версию Minecraft **1.21.11**.
3. Установите клиент — появится новый профиль в лаунчере.

## Установка мода

1. Скачайте файл `duck-util-<версия>.jar` (например, `duck-util-3.2.2.jar`).
2. Откройте папку с играми Minecraft:
   - Windows: `%appdata%\.minecraft`
3. Перейдите в папку `mods` (создайте её, если нет).
4. Скопируйте JAR-файл мода в папку `mods`.
5. Убедитесь, что в папке `mods` также лежит Fabric API.

## Проверка установки

Запустите клиент через профиль Fabric. В консоли или логе (`latest.log`) должно появиться сообщение:

```
[main/INFO] [duck-util/]: Hello Fabric world!
```

Если мода нет в списке (`моды` в главном меню), проверьте:
- Версию Minecraft (должна быть 1.21.11)
- Наличие Fabric API в папке `mods`
- Что JAR не повреждён

## Обновление

1. Удалите старый JAR-файл из папки `mods`.
2. Скопируйте новый JAR-файл.
3. Конфигурация сохраняется автоматически — настройки не сбросятся.

> ⚠️ При обновлении версии мода проверьте файл `whats-new.txt` — там описаны изменения для текущей версии.
