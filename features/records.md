# Запись экрана

Можно записывать сессии игры и сохранять важные моменты.

## Возможности

- Запись экрана в реальном времени
- Клипы до бана (+5 секунд до события)
- Клипы при ревизии читов
- Интеграция с OBS через модуль `Obs`
- Просмотр записей в меню мода (Records View)

## Настройки

Настройки записи находятся в разделе `rec/` и включают:
- Путь сохранения записей
- Максимальная продолжительность клипа
- Качество записи

## Просмотр записей

Записи доступны через интерфейс мода (Records View), где можно:
- Посмотреть список записей
- Воспроизвести запись
- Удалить старые записи
