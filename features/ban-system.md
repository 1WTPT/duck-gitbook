# Система банов

Duck Util отслеживает баны в игровом чате и ведёт архив всех банов.

## Учёт банов

При получении бан-сообщения в чате мод:
- Записывает ник забаненного игрока
- Записывает причину бана
- Записывает дату и время (по МСК)
- Показывает уведомление (тост)

## Архив банов

Все баны сохраняются в папке:
```
Duck Util/Баны/
```

Прошлогодние баны переносятся в подпапки по годам:
```
Duck Util/Баны/2025/
```

## Резервный лог

Файл `Duck Util/Резервный лог банов.txt` содержит каждый бан, даже если учёт банов отключен. Файл только дописывается — его не следует чистить или удалять.

## Ban Effects

Визуальные эффекты при получении бана:
- Различные визуальные эффекты на экране
- Превью эффектов в меню модуля
- Настройка интенсивности и типа эффекта

## Уведомления о банах

Уведомления показываются в виде тостов в углу экрана с информацией о забаненном игроке и причине.
