# Социальные функции

Duck Util включает социальные возможности для взаимодействия с другими игроками.

## VK-интеграция

- Авторизация через ВКонтакте
- Бот для администрирования (AdmBot)
- Отправка и получение сообщений
- Фото и обложки видео из ВК

## Игры

### Дурак
Карточная игра «Дурак» с другими игроками на сервере. Команды `/durak/*` для управления игрой.

### Бильярд
Бильярдный симулятор. Команды `/play/*` для начала игры.

### Змейка
Классическая змейка с рекордом, сохраняемым локально.

## Топы игроков

- «В сети» — список игроков онлайн
- «Топы» — рейтинги по играм (дурак считает сервер)
- КПД (коэффициент полезного действия) синхронизируется через `kpd.js`

## Социальный экран

Доступен из главного меню мода, показывает статус друзей, топы и активные игры.
