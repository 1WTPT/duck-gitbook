# HUD и оформление

Элементы HUD (heads-up display) отображаются на экране поверх игры и можно перемещать, настраивать и скрывать.

## Редактор HUD

Откройте редактор HUD из главного меню Duck Util. В редакторе можно:
- Перетаскивать элементы мышкой
- Изменять размер и оформление каждого элемента
- Скрывать или показывать элементы
- Настраивать цвета и прозрачность

## Элементы HUD

| Элемент | Описание |
|---------|----------|
| **Watermark** | Версия мода, канал и информация о сессии в углу экрана |
| **Медиаплеер** | Информация о текущем треке с обложкой |
| **Цель** | Информация о выбранном игроке: дистанция, здоровье, эффекты |
| **Координаты** | Позиция игрока (X, Y, Z) и направление |
| **FPS** | Количество кадров в секунду |
| **Задержка** | Ping до сервера |

## Настройки HUD

Настройки находятся в модуле **HUD**:
- Плотность фона под элементами HUD
- Свечение краёв
- Масштаб элементов
- Анимации появления и исчезновения

Каждый элемент имеет свой стиль оформления, который можно изменить в редакторе HUD.

## Сохранение макета

Макет HUD сохраняется автоматически при перемещении элементов. Настройки привязаны к конкретному компьютеру (локальный конфиг).
