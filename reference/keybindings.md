# Клавиши и привязки

Список клавиш по умолчанию для Duck Util.

## Главные клавиши

| Клавиша | Действие | Контекст |
|---------|----------|----------|
| `Right Shift` | Открыть главное меню Duck Util | В любой момент |
| `V` | Открыть меню цели | В игре, с лицензией |

## Клавиши модулей

| Модуль | Клавиша | Действие |
|--------|---------|----------|
| Auto Scan | `F6` / `F7` | Начать / остановить сканирование |
| Zoom | Не назначена | Активация зума (назначается в настройках) |

## Настройка клавиш

Клавиши можно перенастроить:
1. Через настройки модуля (для модульных клавиш)
2. Через стандартные настройки Minecraft (для Right Shift)
3. В коде клавиши регистрируются через `KeyBindingHelper.registerKeyBinding`

## Категория

Все клавиши мода относятся к категории `key.duck-util.main` (ID: `duck-util:main`).

## Список клавиш в коде

| Поле | Клавиша по умолчанию |
|------|---------------------|
| `openKey` | `GLFW_KEY_RIGHT_SHIFT` |
| `zoomKey` | `GLFW_KEY_UNKNOWN` (не назначена) |
| `targetMenuKey` | `GLFW_KEY_V` |

Клавиши привязок (`Setting.Bind`) не сбрасываются к умолчанию при сбросе настроек модуля.
