# Интерфейс в скриншотах

Настоящие снимки интерфейса и визуальных сцен. Версия указана в подписи: базовые экраны — 3.3, новые эффекты — 3.4, снежное оформление New Year Mode — 3.5. Для примеров проверок, заявок, отчётов и сетевых функций использованы демонстрационные ники и данные. Нажмите на изображение, чтобы рассмотреть его в полном размере.

## New Year Mode — 3.5

Снежное оформление включается в **Right Shift → Разное → Interface → Меню → New Year Mode**. По умолчанию выключено. Все снимки ниже сделаны в отдельном тестовом клиенте; HUD сохраняет обычный вид.
