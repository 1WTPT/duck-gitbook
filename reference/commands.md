# Команды

Список команд Duck Util.

## Основные команды

| Команда | Описание |
|---------|----------|
| `/dupeip` | Проверить связанные аккаунты по IP |
| `/wc` | Найти игроков (используется в автоскане) |
| `/rmc` | Команда модерации |
| `/dp` | Действие модерации |

## Чеат-детекция

| Команда | Описание |
|---------|----------|
| `/cdstart ник\|me\|all [cheat\|legit]` | Начать проверку игрока на читы |
| `/revise finish <чит>` | Завершить ревизию читера |

## Модуль целей

| Команда | Описание |
|---------|----------|
| `/cheats/*` | Команды базы читов |

## Социальные игры

| Команда | Описание |
|---------|----------|
| `/durak/*` | Управление игрой в дурака |
| `/play/*` | Управление бильярдом |

## История и ветки

| Команда | Описание |
|---------|----------|
| `/history` | История игрока (для ветки аккаунтов) |
| `/report` | Жалоба на игрока (для ветки аккаунтов) |

## Примечания

- Подсказка ников из таба для последнего слова аргумента реализована через `suggestPlayers`.
- Меню цели открывается клавишей **V** (не команда).
- Основное меню мода открывается клавишей **Right Shift**.
