# Локальный конфиг

Локальный конфиг хранит настройки только для этого компьютера.

## Путь

```
config/duck-util-local.json
```

## Что хранится локально

- Ключи доступа (VK, Tink, лицензия)
- Пути к файлам и папкам
- Ники на скриншотах
- Другие персональные данные

## Управление

Локальный конфиг можно переключить через системное свойство:
```
-Dduck-util.configs=<временная_папка>
```

## Безопасность

> ⚠️ Ключи (`-vk.json`, `-tink.json`, `-license.json`) следует убирать перед запуском клиента и возвращать по хешу после. Не храните секретные данные в открытом виде.

## Синхронизация

Локальный конфиг НЕ синхронизируется между компьютерами. Каждый ПК имеет свой собственный локальный конфиг.
