# Duck Config — общий конфиг

`DuckConfig` управляет общими настройками мода, синхронизируемыми между компьютерами.

## Структура

Конфиг хранит значения всех настроек модулей с ключами `Setting.key`.

## Перенос настроек

Когда настройка переезжает из одного модуля в другой (например, из Interface в Theme или HUD), используется поле `movedFrom`. При загрузке конфига:
1. Ищется по ключу (`key`)
2. Если не найден — по названию (для совместимости со старыми конфигами)
3. Значение из старого конфига переносится на новую настройку

## Локальные настройки

Настройки с флагом `local` (только этот компьютер):
- Не попадают в общий конфиг (.duck)
- Не меняются у других пользователей
- Примеры: свой ник на скриншотах, личные пути

## Сохранение

Конфиг сохраняется атомарно:
1. Данные пишутся во временный файл (`.tmp`)
2. Выполняется `ATOMIC_MOVE` в целевой файл
3. Это prevents повреждение конфига при сбоях записи

При нехватке места `writeString` может оставить файл пустым — важные файлы пишутся через этот механизм.
