# Система конфигурации

Duck Util использует многоуровневую систему хранения настроек.

## Уровни конфигурации

| Уровень | Путь | Описание |
|---------|------|----------|
| **Общий конфиг** | `Duck Util/` (`.duck`) | Настройки, синхронизируемые между ПК через облако |
| **Локальный конфиг** | `config/duck-util-local.json` | Только этот ПК (ключи, пути, ники) |
| **Ключи** | `-vk.json`, `-tink.json`, `-license.json` | Секретные ключи (удалять перед запуском, возвращать по хешу) |

## DuckConfig

Система настроек `DuckConfig`:
- Ключ — `Setting.key`
- Перенос настроек — `movedFrom` (когда настройка переехала из одного модуля в другой)
- Сохранение — атомарное (`.tmp` + `ATOMIC_MOVE`)

## Облачные конфиги

Облачные настройки хранятся в `CloudConfigs` и синхронизируются через `configs.js`.

## Формат файлов

Конфиги хранятся в JSON формате. Резервные копии создаются с расширением `.json.bak` перед прогонами тестов.

> ⚠️ Перед запуском клиента в режиме тестирования обязательно сделайте копию конфигов и верните их после.
