# Облачные конфиги

Облачные настройки синхронизируются между компьютерами через сервер лицензирования.

## CloudConfigs

Класс `CloudConfigs` управляет облачными настройками:
- Синхронизация через `configs.js`
- Доступны только с активной лицензией
- Общие настройки (.duck) доступны на всех ПК пользователя

## Что синхронизируется

- Настройки модулей (кроме локальных)
- Темы оформления
- Макет HUD
- Привязки клавиш
- Otras пользовательские настройки

## Что не синхронизируется

- Локальные настройки (`local: true`)
- Ключи доступа
- Персональные пути
- Резервные логи банов

## Доступ

Облачные конфиги доступны через веб-интерфейс сервера лицензирования и автоматически загружаются при запуске клиента с активной лицензией.
