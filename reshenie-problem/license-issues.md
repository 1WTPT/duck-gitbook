# Проблемы с активацией

В **3.3** окно активации показывает причину сбоя и подсказку в несколько строк. Одна общая фраза больше не используется для всех исключений.

| Сообщение | Что проверить |
| --- | --- |
| Таймаут подключения | Интернет, прокси и доступность сервиса; повторите попытку. Это `HttpConnectTimeoutException`. |
| Таймаут ответа | Сервер не успел ответить; подождите и повторите попытку. Это `HttpTimeoutException`. |
| Не удалось установить TLS | Дату и время Windows, прокси и настройки антивируса. Это `SSLHandshakeException`; другие ошибки TLS также показываются отдельно. |
| Не найден адрес сервера (DNS) | Подключение и настройки DNS. |
| Соединение прервано | Стабильность сети; повторите попытку. |
| Вместо JSON пришла HTML-страница | Получен ответ промежуточного сервера или неверного адреса. При повторении сообщите администратору. |
| Некорректный JSON | Неподходящий формат ответа, например при `JsonSyntaxException`. Сообщите администратору, если повтор не помог. |
| HTTP 502, 503 или 504 | Сервис временно недоступен; попробуйте позже. |

## Ключ не принимается

Проверьте, что ключ скопирован целиком. Сообщения **Ключ не найден**, **Ключ заблокирован**, **Ключ привязан к другому компьютеру** и **Версия устарела** означают отдельный отказ сервера. За ключом или сбросом привязки обратитесь к администратору, выдавшему мод.

## Лицензия перестала работать

Проверьте текст ошибки и версию мода. Действующий сохранённый токен позволяет продолжить работу при временной недоступности сервера до окончания срока. Не удаляйте файлы лицензии наугад.

Для обращения передайте версию Duck Util и текст сообщения. **Не отправляйте ключ, токен или полный ответ сервера.**
