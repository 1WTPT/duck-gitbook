# Система модулей

Модули — основные функциональные блоки Duck Util. Все модули наследуются от `dev.wantop.module.Module`.

## Класс Module

| Поле | Описание |
|------|----------|
| `name` | Название модуля |
| `description` | Описание (подсказка над меню) |
| `icon` | Иконка модуля |
| `category` | Категория модуля |
| `settings` | Список настроек модуля |
| `alwaysOn` | Всегда включён (без переключателя) |
| `hidden` | Скрыт из меню |
| `resettable` | Кнопка сброса настроек в шапке |
| `enabled` | Включён ли модуль |

## Основные методы

| Метод | Описание |
|-------|----------|
| `add(setting, description?)` | Добавить настройку с описанием |
| `toggle()` | Переключить состояние модуля |
| `setEnabled(on)` | Включить/выключить модуль |
| `isEnabled()` | Проверить, включён ли модуль (учитывает лицензию) |
| `resetSettings()` | Сбросить настройки к умолчанию |
| `settingsDefault()` | Проверить, все ли настройки по умолчанию |
| `onTick(client)` | Вызывается каждый тик, если модуль включён |

## Регистрация модулей

Все модули регистрируются в `Modules.ALL` в порядке регистрации — это порядок отображения в меню.

```java
public static final Interface INTERFACE = reg(new Interface());
public static final Theme THEME = reg(new Theme());
// и так далее
```

## Лицензия

Модуль работает только если `License.ok()` возвращает true. Без лицензии все модули (кроме Interface, Theme, Optimization) отключены.

## Настройки модулей

Настройки наследуются от `Setting` и могут быть:
- `Setting.Bool` — флажок
- `Setting.Slider` — ползунок
- `Setting.Mode` — выбор варианта
- `Setting.Multi` — несколько флажков
- `Setting.Text` — текстовое поле
- `Setting.Color` — выбор цвета
- `Setting.Bind` — привязка клавиши

Каждая настройка имеет:
- `name` — название
- `key` — ключ в конфиге
- `description` — подсказка
- `visibleWhen` — условие показа
- `local` — только этот компьютер
- `section` — заголовок раздела
