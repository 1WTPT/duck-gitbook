# Система настроек

Настройки модулей реализованы через иерархию классов `Setting`.

## Типы настроек

| Тип | Класс | Описание |
|-----|-------|----------|
| Bool | `Setting.Bool` | Флажок вкл/выкл |
| Slider | `Setting.Slider` | Числовой ползунок с минимумом, максимумом и шагом |
| Mode | `Setting.Mode` | Выбор одного из нескольких вариантов |
| Multi | `Setting.Multi` | Несколько независимых флажков |
| Text | `Setting.Text` | Текстовое поле с ограничением длины |
| Color | `Setting.Color` | Выбор цвета из палитры или по коду `#RRGGBB` |
| Bind | `Setting.Bind` | Привязка клавиши (клавиши не сбрасываются к умолчанию) |

## Поля Setting

| Поле | Описание |
|------|----------|
| `name` | Название настройки |
| `key` | Ключ в конфиге (по умолчанию = name) |
| `description` | Подсказка над меню при наведении |
| `visibleWhen` | Условие показа (BooleanSupplier) |
| `tag` | Плашка («Тест», «Важно», «Дебаг») |
| `movedFrom` | Старый модуль для переноса значения |
| `section` | Заголовок раздела над настройкой |
| `local` | Только этот компьютер (не в общий конфиг) |
| `resets` | Поставщик настроек для сброса (кнопка ↺) |

## Работа со значениями

- `captureDefault()` — запомнить текущее значение как умолчание
- `isDefault()` — проверить, equals ли текущее значение умолчанию
- `reset()` — вернуть значение к умолчанию
- Для `Color` есть методы `get()`, `set(int rgb)`, `code()`, `syncHsv()`, `hsv()`, `rgb()`

## Цветовая система

`Setting.Color` поддерживает:
- Авто-цвет (по теме) с `autoLabel` и `fallback`
- Пользовательский цвет (value >= 0)
- Готовые цвета в палитре (`presets`)
- Недавние цвета (до 14, общие для всех цветов)
- Поле ввода кода `#RRGGBB`
- HSV-перевод для сохранения оттенка у серых/чёрных цветов
