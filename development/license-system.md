# Лицензирование

Duck Util использует систему лицензирования на основе ключа и HWID.

## Компоненты

| Класс | Описание |
|-------|----------|
| `License` | Проверка лицензии, HWID, токен Ed25519 |
| `LicenseScreen` | Экран ввода ключа |
| `VkAuth` | Авторизация через ВКонтакте |
| `AdmBot` | Бот для администрирования |

## Как работает

1. Пользователь вводит лицензионный ключ
2. Система вычисляет HWID компьютера
3. Ключ + HWID отправляются на сервер лицензирования (`duck-license-server/`, Node.js)
4. Сервер возвращает токен Ed25519 (`uid`)
5. Токен сохраняется и используется для проверки при каждом запуске

## `License.ok()`

Метод `License.ok()` возвращает true, если лицензия активна. Все модули (кроме Interface, Theme, Optimization) проверяют это перед работой.

## Режим разработчика

В режиме разработчика (`License.DEV`) лицензия не требуется. Все функции доступны без ключа.

## Минимальная версия

Версия мода записывается в `../duck-license-server/min-version.json`. После деплоя сервера версии ниже минимальной не допускаются.

## Безопасность

> ⚠️ Ключи (`-vk.json`, `-tink.json`, `-license.json`) следует убирать перед запуском клиента и возвращать по хешу после запуска.
> Рефлексию по именам классов мода не заводить.
